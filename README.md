# C.H.O.R.E.S.
CompreHensive Onboard Resource Evaluation Screen
A KSP mod that shows detailed information about the resources currently in your vessel, such as density, volume and total mass.

In the editor, it shows the stats of the resources currently in the vessel, updating whenever anything is changed

In flight, you can change how often the vessel resources are scanned, from 0.5 to 10 seconds

You can also turn off automatic scanning and scan manually with the Refresh button

Note: this is my first c# mod so there might be bugs! Half the time it took to make this was spent searching up "how does this work in C#"
